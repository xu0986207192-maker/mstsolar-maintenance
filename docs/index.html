🔢 PR 值與 RA 值計算器

📊 PR 值（Performance Ratio）計算

PR 值 = 實際發電量 ÷ (日照強度 × 系統容量 × 時數) × 100%

計算結果：
評價標準：
優良：PR ≥ 80% | 良好：70% ≤ PR < 80% | 普通：60% ≤ PR < 70% | 需改善：PR < 60%

⚡ RA 值（直流發電效率）計算

計算公式：RA = PA ÷ (PO × GI/1000) = PA × 1000 ÷ (PO × GI)
PA：組列輸出功率（W） | PO：組列額定功率（W） | GI：現場日照強度（W/m²）

實際量測的組列輸出功率
組列額定功率（模組總和）
量測時的現場日照強度（必填）
實際量測時的模組溫度（記錄用）
計算結果：
評價標準：
優良：RA ≥ 95% | 良好：90% ≤ RA < 95% | 普通：85% ≤ RA < 90% | 需注意：80% ≤ RA < 85% | 需改善：RA < 80%
註：RA 值反映太陽能模組在特定環境條件下的實際發電效率。標準測試條件(STC)為 25°C、1000 W/m²。
